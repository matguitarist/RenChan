Walkthroughs beside the game, your own mods, and a compatibility report.

- Keep a game's PDF or text walkthrough (like Eternum's on itch.io) and read it in a window that floats above the game, back at the page you left. Game › Show Walkthrough (⇧⌘J).
- Make your own mod: New Mod… starts one from a template and opens it in your editor. Mods can use RenChan's mod API (start and load hooks, an F8 mods menu, keys, state kept outside saves); see docs/MODDING.md.
- Turn on Ren'Py's console (Shift+O) and fast skip (>) for any game.
- See how each game last ran, and export a compatibility report for bug reports (File › Export Compatibility Report…).
