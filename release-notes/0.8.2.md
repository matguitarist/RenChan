- A runtime download that drops halfway picks up where it stopped instead of starting over, and is checked against renpy.org's checksum before it is installed.
- Adding a game or a mod from a zip is safer: a zip that would write outside its folder, or one that fails halfway, leaves nothing behind.
- Importing a big game or installing a runtime can no longer hang on a tool's long output.
- If RenChan can't read its library, it keeps the file aside instead of saving over your games.
- Stop now ends a game together with everything it started, even a game that doesn't quit when asked.
- Quitting RenChan right after a change saves your library in the right order, so the newest change is the one kept.
