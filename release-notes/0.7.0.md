- Browse a game's saves (Game › Browse Saves…, ⇧⌘B): each save with its picture, name, place, date and playtime, and the modded saves apart.
- Change a save's on/off values, numbers and text. RenChan backs up the saves first, and the game loads the changed save as usual, with no warning.
- Change the screen filter while the game runs: another filter, None or a new strength shows within a second.
- Write your own filter with the game open: each save of its .glsl file shows in the game, and a shader with a mistake keeps the last filter and shows the compiler's error.
- Big libraries stay smooth: the library is written in the background, covers take far less memory, and the inspector stops reading the disk on every redraw.
