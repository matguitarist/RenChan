Screen filters, and finding the games already on your Mac.

- Lay a screen filter over any game: Sharpen, CRT, Night Warmth, Grayscale, or a color-blindness filter (protanopia, deuteranopia, tritanopia), with a Strength slider. The game itself is never changed.
- Move Strength while the game runs and see it change right away.
- Add your own .glsl shader as a filter; it shows up for every game.
- File › Find Games on This Mac… lists the Ren'Py games in Applications, Games, Downloads and the Desktop that aren't in your library yet, and adds the ones you pick.
