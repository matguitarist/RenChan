# RenChan — Glossary

One name per thing, in every button, menu, title, tooltip and error.

| Term | Means | Not | French |
| --- | --- | --- | --- |
| Game | One Ren'Py visual novel in the library | title, novel, VN | Jeu |
| Library | Every game RenChan knows | collection | Bibliothèque |
| Runtime | An official Ren'Py SDK RenChan downloaded to play games | engine, SDK | Moteur |
| Working copy | RenChan's APFS clone of a game, the only copy it changes | clone, sandbox | Copie de travail |
| Saves | The game's save files in ~/Library/RenPy | save data | Sauvegardes |
| Playtime | Total time a game has run from RenChan | time played | Temps de jeu |
| Last Played | When a game last started | last run | Dernière partie |
| VNDB | The Visual Novel Database, where details and covers come from | | VNDB |
| Details | Developer, release date and description from VNDB | info, metadata | Détails |
| Cover | The picture for a game in the grid and inspector | thumbnail, art | Couverture |
| Status | Not Started, Playing or Finished, set by the person | progress, state | Statut |
| Rating | One to five stars | score | Note |
| Label | A word the person puts on games to group them | tag, category | Étiquette |
| Notes | Free text the person keeps about a game | comments | Notes |
| Backup | A dated copy of a game's saves RenChan keeps | snapshot, save copy | Copie (des sauvegardes) |
| Restore | Put a backup's saves back in place of the current ones | revert, load | Restaurer |
| Screen filter | A shader RenChan lays over the whole game, in its copy only | Effect, shader, mod | Filtre d’écran |
| Strength | How much of a filter shows, 0 to 100% | Intensity, amount | Intensité |
| Mod | Files RenChan puts under a game's game/ folder in its own copy: a walkthrough, URM, a patch | add-on, plugin, patch | Mod |
| Mod library | RenChan's one copy of every mod added, shared by the games that use it | mod store | Bibliothèque (de mods) |
| Load order | The order of a game's mods; a later mod wins a file both have | priority | Ordre de chargement |
| Modded saves | The saves of play with mods on, kept apart from the game's | mod saves | Sauvegardes avec mods |
| Walkthrough | A PDF or text guide kept with a game and read in its own window; a walkthrough mod is a mod | guide, soluce file | Soluce |
| Watch | The itch.io page or F95zone thread RenChan reads for a game's new versions | Follow, subscribe, track | Suivre |
| Game Version | The game's own version, such as 0.9, read from config.version or its folder name | Ren'Py version | Version du jeu |
| New version | A version on the watched page newer than the game's | Update (the action) | Nouvelle version |
